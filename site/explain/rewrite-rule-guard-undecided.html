rewrite-rule-guard-undecidedA `rewrite` rule matched, but its guard needed a runtime value

Reported by --explain after a verdict.

mettle explain rewrite-rule-guard-undecided

A where clause is evaluated at compile time, on the constants bound at the match site. Every match bound a parameter the guard reads to a value only known at run time, so the guard could not be decided and the rule did not apply.

Fix: if the rule holds for every value, drop the guard. If it does not, the guard is doing its job, and only sites with constant arguments qualify.
